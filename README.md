# Projeto: ParadaStar Cliente
Disciplina: Desenvolvimento de Aplicações Mobile I

### Objetivo

O ParadaStar Cliente é um aplicativo desenvolvido para modernizar a experiência de usuários em estacionamentos, oferecendo
uma interface digital intuitiva para gerenciar a ocupação de vagas em tempo real. O foco principal é proporcionar autonomia ao cliente

### Funcionalidades

* Registro de ocupação da vaga utilizando ID da vaga, placa e modelo do veículo.
* Monitoramento em tempo real da vaga ocupada e dos dados do veículo.
* Sistema de login e cadastro integrado ao Firebase Authentication.
* Armazenamento de dados integrado ao Firebase Realtime DataBase. 

### Tecnologias Utilizadas
* Java
* Android SDK
* Firebase Authentication
* Firebase Realtime Database
* XML Layouts

### Finalidade Acadêmica

Trabalho prático desenvolvido para fins de aprendizado em desenvolvimento Android Nativo.
